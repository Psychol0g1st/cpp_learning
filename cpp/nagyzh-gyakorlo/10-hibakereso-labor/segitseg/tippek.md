# Segítség

Ne egyszerre keresd az összes hibát.

Javasolt sorrend:

1. Először azt javítsd, amitől a program le sem fut rendesen.
2. Utána azt, ami rossz állapotváltozást okoz.
3. Végül a kimenetet ellenőrizd soronként.

Figyeld Watch ablakban:

```txt
products.size()
quantities.size()
money
index
```
