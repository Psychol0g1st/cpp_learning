# 10 - Hibakereső labor

Ebben a feladatban nem nulláról kell programot írnod, hanem egy hibás kódrészletet kell kijavítanod az elvárt viselkedés alapján.

## Fájl

Nyisd meg:

```txt
projekt/store_reszlet.cpp
```

## Elvárt viselkedés

A program egy egyszerű boltot modellez.

Elvárt kimenet:

```txt
add chair done
buy existing ok: 1, money: 3000
buy too many: 0, money: 3000
buy missing: 0, money: 3000
buy too expensive: 0, money: 1000
```

## Feladat

1. Futtasd a programot.
2. Jegyezd fel az első hibát vagy eltérést.
3. Javíts egy hibát.
4. Futtasd újra.
5. Ismételd, amíg a kimenet egyezik.
6. Minden javított hibához tölts ki egy hibanapló-bejegyzést.

## Szabály

Ne írd újra az egész programot. A cél az, hogy megtaláld és kijavítsd a hibákat.
